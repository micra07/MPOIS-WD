# Низкоуровневая архитектура компонентов системы

Система развернута на виртуальном хостинге SpaceWeb. Состоит из клиентской части, сервера приложений, базы данных и механизмов фоновой обработки.

## Компоненты

**Клиент (Браузер)**
Отправляет HTTP/HTTPS-запросы и отображает интерфейс. Работает на устройстве пользователя.

**Web-сервер (Nginx)**
Принимает все входящие запросы. Отдает статические файлы (CSS, JS, изображения) напрямую из папки `public/`, чтобы не нагружать PHP. Динамические запросы передает Laravel через PHP-FPM.

**Laravel Application (PHP 8.x)**
Ядро системы. Обрабатывает бизнес-логику, маршрутизацию и авторизацию. Генерирует HTML-страницы и API-ответы.

**MySQL (База данных)**
Хранит структурированные данные: профили пользователей, заявки, сообщения чата, каталог услуг. Laravel взаимодействует с ней через ORM Eloquent.

**File Storage (`storage/app/public`)**
Файловая система хостинга. Хранит загруженные пользователями фотографии и документы. Laravel сохраняет файлы физически, а в базу данных записывает только пути к ним и метаданные.

**Очередь задач (Queue) и Обработчик (Worker)**
Механизм для фоновой обработки. Laravel кладет тяжелые задачи (отправка писем, обработка фото) в очередь. Worker подхватывает их и выполняет в фоне, не задерживая ответ сервера пользователю.

**Email-сервис**
Внешний SMTP-сервер. Worker отправляет через него транзакционные письма: подтверждения заявок и уведомления из чата.
